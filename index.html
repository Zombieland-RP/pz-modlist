You subscribe to nothing. Connect with the details in the server-info channel; the game downloads the server's pack from the Workshop on connect and enables the right mods. Let that download finish the first time.

Do not install any mod the pack contains on your own, from the Workshop or as a local copy: the server checks every client's mods on connect and refuses a second copy until it is removed.

The server requires the free ZombieBuddy add-on. On your first connect the game shows its installer; install it, restart your game and connect again. It is the client half of the server's integrity check and changes nothing in play.

After a patch, restart your game so Steam applies the update before you connect.

ZL Double Door FixZombieland RP

Fixes a vanilla 42.20.4 crash: a double gate whose leaves have been partly removed makes IsoDoor.getDoubleDoorIndex return an out-of-range index, which throws inside the client main loop and drops the player to the main menu, and aborts the server's gate-destruction packet. Engine fix only, no gameplay change.

ZL Loot DirectorZombieland RP

ZL No Attacking From VehiclesZombieland RP

Disables attacking (firearms and melee) while seated in a vehicle. Build 42 lets a seated player shoot/swing through an open or broken window; this re-asserts IsoPlayer.setBannedAttacking(true) every tick while in a vehicle and restores it on exit. Client-side, protected by the Lua checksum.

ZL PaceZombieland RP

Zombieland pacing decisions against vanilla real-time clocks, kept together so the reasoning lives in one place. Nights shortened by driving GameTime.multiplier (ZLNightPace, DayLength-aware); broken bones capped at 3 real days wall-clock including offline time (ZLFracturePace); leather drying times set from Lua after script load so the recipe script version stays vanilla and a ring flip cannot destroy hides on racks, with a boot-time assertion (ZLLeatherPace). Not yield levers - see ZLYieldSync for anything that changes how much a system outputs.

ZL SafehouseZombieland RP

The safehouse permission system in one place: who may build, destroy, scrap, take or claim inside a claim. Members and safehouse administrators (CanSetupSafehouses) only; presence is never authorisation. Client cursors and menus ask the rule for honest feedback, the server re-asks it on every action. Also the widened claim whitelist, the claim size cap, and the optional purchase: a safehouse bought per tile in cash, only in your faction's town (sandbox switches, off by default). Pairs with the ZLSafehouse server jar.

ZL Security DoorsZombieland RP

Every security door (the map's police/military metal doors, police jail cell doors and the Knox Buildworks Security Door build) becomes max-level territory: the crowbar is refused outright, melee damage only sticks at Strength 10, sledgehammer/dismantle/blowtorch cut-open need Metal Welding 8 (server-validated), nothing can pick one up. Safehouse members are exempt on their own base. Building one takes Metal Welding 7 + sheet metal/bars/hinges/torch/mask and yields 2500 HP.
